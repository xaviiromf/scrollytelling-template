# Phuyu y la Fantasma — Scrollytelling Experience

Una experiencia editorial inmersiva y poética dedicada a la banda chilena **Phuyu y la Fantasma** (Chillán), fusionando la anticueca de Violeta Parra con la visceralidad del noise rock y el post-hardcore.

## 🌿 Concepto y Filosofía
- **Phuyu:** Voz quechua para nube / niebla.
- **Narrativa Estricta:** La cronología se despliega a través de actos identificados bajo el formato **`Acto X — 202X`**, recorriendo desde sus orígenes solitarios de dormitorio en 2020 hasta la reconstitución monumental de sus *Anticuecas Subterráneas* el 1 de octubre de 2026.
- **Tratamiento Artístico de Medios:** Eliminación de encuadres genéricos. Las imágenes se integran orgánicamente con máscaras de gradiente radial, grano analógico, capas duotono y paralaje sutil.

## ⚡ Stack Tecnológico
- **Frontend:** React 18 + TypeScript + Vite.
- **Scrollytelling:** GSAP (ScrollTrigger) + Lenis Smooth Scroll.
- **Estilos:** Tailwind CSS + Google Fonts (Cormorant Garamond & Space Grotesk) + Ruido SVG.
- **Iconografía:** Lucide React.
- **Arquitectura:** 100% estático (cero dependencias de backend).

## 🚀 Instalación y Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción (despliegue estático en Vercel, Netlify o GitHub Pages)
npm run build
```
